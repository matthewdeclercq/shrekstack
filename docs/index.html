The problem

Agents work blind when they can’t see what’s true.

  • Plans get scattered. Which file is right?
  • Docs and code disagree. The agent trusts the wrong one.
  • Nobody remembers the why.

The idea

Every fact gets one home.

And agents keep it current. No copies. No guessing.

  • Single source of truth.
  • Docs match the code.
  • Proven work.

The full toolkit

Twelve skills. Three rhythms.

Once per repo
  • bootstrap-repoSets up the rules and the docs.
  • bootstrap-verifyTeaches agents how to test this app.
  • bootstrap-uiWrites down how screens should look.
Day to day
  • ship-itRuns the checks below, in order.
  • tidyCleans up the work just finished.
  • blast-radiusFinds what a change could break.
  • doc-stewardKeeps the planning docs in shape.
  • doc-syncFixes docs that drifted from the code.
  • commit-groupMakes clean, logical commits.
Now and then
  • prune-codeRemoves dead code, after proof.
  • prune-testsRemoves tests that guard nothing.
  • maintain-verifyKeeps the testing guide fresh.
